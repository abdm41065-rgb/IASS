# Creative Studio — فريق من 5 وكلاء للأفكار الإبداعية

ترسل رفرنس (فيديو/صور) → يتحول لمكتبة أفكار → تُطوَّر وتُقيَّم → استراتيجية جاهزة.

| # | الموظف | المهمة |
|---|---|---|
| 1 | `VisualAnalyst` | يفكك الفيديو/الصورة: ألوان، خطوط، تكوين، إيقاع، Hook |
| 2 | `BrandGatekeeper` | يقبل/يرفض حسب هويتنا: قواعد صارمة بالكود (ممنوعات، مسافة ألوان، جودة) + حكم Claude |
| 3 | `IdeaResearcher` | يولّد أفكاراً (مع نسخ A/B) من الرفرنسات المقبولة + ترند المنصات، ويمنع التكرار |
| 4 | `IdeaEvaluator` | يقيّم بأوزان قابلة للضبط، يدمج رأي النموذج مع بيانات التفاعل الفعلية وأدائنا السابق |
| 5 | `StrategyBuilder` | أعمدة محتوى، تقويم 4 أسابيع، KPIs، اختبارات A/B، مخاطر |

## الإضافات
- **حلقة تحسين**: الأفكار بحكم `revise` تُعاد صياغتها وتُقيَّم مرة ثانية تلقائياً.
- **فيتو الهوية**: أي فكرة `brand_fit < 50` تُرفض مهما كانت درجتها.
- **تطبيع التفاعل لكل منصة** (percentile) + **وزن حداثة** + **كشف التشبّع** (نمط مكرر كثيراً يُخصم).
- **حلقة تعلّم**: `feedback` يسجّل الأداء الفعلي فتتعدل توقعات التقييم القادمة.
- **مكتبة أفكار دائمة** (SQLite) مع إزالة التكرار بين الجلسات.
- **حماية الاستراتيجية**: الكود يحذف من التقويم أي فكرة غير معتمدة.
- **بدون مفتاح**: الاختبارات تعمل بـ `MockLLM`.

## التشغيل
```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...
# عدّل brand/brand.yaml ثم:
python -m studio.cli run ref1.mp4 ./images --sources samples/sources.yaml --ideas 20 --out report.md
python -m studio.cli feedback <idea_id> --engagement-rate 0.062
python -m unittest discover -s tests
```
الفيديو يحتاج `ffmpeg` (أو مرّر إطاراته كصور).

## الواجهة (بدون سطر أوامر)
```bash
python -m studio.web   # ثم افتح http://127.0.0.1:8000
```
ارفع الرفرنسات وملف بيانات المنصات، واضغط تشغيل. خيار **الوضع التجريبي** يجرّب الواجهة بدون مفتاح (نتائج ثابتة وليست تحليلاً حقيقياً).

## الجلب التلقائي للرفرنسات (YouTube)
```bash
export YOUTUBE_API_KEY=...    # مجاني: Google Cloud → YouTube Data API v3
python -m studio.cli run --discover "luxury perfume ad, عطور فاخرة" --region SA --top 10
```
يبحث بالكلمات، ويرتّب حسب المشاهدات والتفاعل وجودة التعليقات (أهم تعليقات الجمهور تُرفق للمحلل)، ويحمّل الغلاف وثلاثة إطارات من كل فيديو (بدون تحميل الفيديو نفسه)، ثم يمررها للفريق. نفس الخيار موجود بالواجهة.
الحصة المجانية ~10,000 وحدة/يوم؛ كل بحث يكلّف 100 وحدة.

## مصادر الـ 500+ (تنبيه مهم)
لا يوجد scraping مباشر لإنستغرام/تيك توك/فيسبوك (يخالف شروطها وغالباً يُحظر). الموصلات المدعومة:
ملفات CSV/JSON مصدّرة، أو `HttpConnector` لأي API رسمي/وسيط بمفتاحك (Meta Content Library،
TikTok Research API، YouTube Data API، أو Apify). أضف مصادرك في `samples/sources.yaml`.
