# 📚 مكتبة المراجع — تصميم المواقع

هذا المكان مرجع لتصميم المواقع. كل موقع ترسله يُضاف هنا مع تحليل لعناصر تصميمه،
عشان نبني منه لغة تصميم موحّدة ونطوّرها ونطبّقها على مشروع **IAAS**.

---

## 🎯 الهدف
- تجميع مواقع ملهمة كمرجع بصري.
- استخراج الدروس المفيدة من كل موقع (ألوان، خطوط، حركات، تخطيط).
- تحويل هذه الدروس إلى تحسينات فعلية على تصميم الموقع الحالي.

## 📌 كيف نستخدم هذا المكان
1. ترسل لي رابط موقع (أو صورة / وصف).
2. أحلّله وأضيف له ملف داخل `references/sites/` وأحدّث الفهرس أعلاه.
3. نختار أفضل الأفكار ونطبّقها على `index.html`.
