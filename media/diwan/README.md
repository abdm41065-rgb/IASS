# صور موقع «الديوان»

ارفع صورك هنا بهذه الأسماء بالضبط، وسيتم تركيبها في الموقع تلقائياً:

| الملف | يظهر في |
|---|---|
| `hero.jpg` | الصورة الكبيرة في الواجهة |
| `private.jpg` | بطاقة «مكتب خاص» |
| `desk.jpg` | بطاقة «مكتب مشترك» |
| `meeting.jpg` | بطاقة «قاعة اجتماعات» |
| `training.jpg` | بطاقة «قاعة تدريب» |

## ملاحظات
- الصيغة: `.jpg` أو `.webp` — والحجم المفضّل عرض ١٦٠٠ بكسل أو أقل.
- لا يلزم أن ترفعها كلها؛ أي صورة ناقصة يبقى مكانها فارغاً بشكل أنيق.
- تُضغط الصور عند التركيب لتبقى الصفحة خفيفة.

## من أين تأتي الصور
- صور مكانك الحقيقي (الأفضل).
- أو صور مجانية مرخّصة للاستخدام التجاري من Unsplash أو Pexels.

تجنّب الصور التي تحمل علامة مائية أو مأخوذة من نتائج البحث — تظهر العلامة على الموقع
وتكون ملكاً لأصحابها.
