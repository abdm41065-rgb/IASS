# 📚 منصة الدراسة

تطبيق ويب عربي (RTL) كامل بدون خادم: افتح `index.html` مباشرة بالمتصفح، أو شغّل `python -m http.server 8000` ثم افتح http://localhost:8000.

## الأقسام (15 مكاناً)
| القسم | ماذا فيه |
|---|---|
| 🏠 الرئيسية | إحصائيات، إجراءات سريعة، إعلانات، مهام قادمة |
| 🏫 الصفوف | إنشاء صف (معلم) / انضمام بكود (طالب)، أعضاء، إعلانات، فويزات وملفات ومنشورات وتقدّم كل صف |
| 👨‍🏫 المعلمون | لوحة المعلم: نتائج الفويزات والأدوات. للطالب: دليل المعلمين |
| 🎓 الطلاب | متابعة الطلاب (معلم) / لوحة الشرف والزملاء (طالب)، نقاط XP |
| 📝 الملاحظات | ألوان، وسوم، تثبيت، ملصقات، بحث، مشاركة مع صف، تصدير نص |
| 📁 الملفات | رفع بالسحب والإفلات، معاينة (صور/PDF/فيديو/صوت/نص)، **تمييز** بالألوان والنجوم والوسوم والملصقات |
| 📚 الملازم | ملازم مع تتبّع صفحات القراءة + **إنشاء ملزمة من ملاحظاتك** |
| 🏷️ الملصقات | لوح سحب وإفلات: ملصقات إيموجي وورقات لاصقة قابلة للكتابة |
| 💬 المشاركة | موجز معلومات/أسئلة/مصادر، إعجاب وتعليق وتثبيت، **تصدير/استيراد حزم** (ملاحظات، بطاقات، فويزات) |
| ⏱️ الدراسة | بومودورو يستمر أثناء التنقل، هدف يومي، تسجيل تلقائي |
| 🃏 البطاقات | تكرار متباعد (صناديق لايتنر)، استيراد جماعي، نسخ مجموعات الصف |
| ❓ الفويزات | اختيار/صح-خطأ/قصير، مؤقت، **ترتيب يدوي ▲▼**، لوحة المتصدرين، مراجعة الإجابات |
| ✅ المهام والجدول | مهام بأولوية وموعد، وجدول أسبوعي |
| 📊 التقدم | مخططات دراسة ونتائج، 7 إنجازات |
| ⚙️ الإعدادات | مستخدمون، وضع ليلي، حجم الخط، نسخ احتياطي واستعادة |

## ملاحظات مهمة
- **البيانات محلية** (localStorage + IndexedDB للملفات) داخل متصفحك فقط. الأدوار (معلم/طالب) للتنظيم على الجهاز وليست حماية حقيقية. للمشاركة الحقيقية بين أجهزة مختلفة يلزم ربطها بخادم وتسجيل دخول (مثلاً Supabase).
- تبديل المستخدم من القائمة بأعلى الصفحة لتجربة دور المعلم والطالب.
- النسخة الاحتياطية لا تتضمن محتوى الملفات المرفوعة.
